# FireAtlas visual attachment guide

Recommended order for a seven-slide demonstration:

1. Title: FireAtlas — Responsible Active-Fire Observation Atlas
2. Problem and solution: use the Overview screenshot
3. Exploration: use the Explore Map screenshot
4. Analysis: use the Fire Calendar and Activity Analysis screenshots side by side
5. Interpretation: use the Anomaly Insights screenshot plus the user/data flow diagram
6. Technical design: use the system architecture diagram
7. Impact and limitations: use the Reports screenshot and the statement that detections are observations, not automatically unique fires

The two diagrams are:

- `fireatlas-system-architecture.svg`
- `fireatlas-user-data-flow.svg`

The demonstration must be either a public video of 30 seconds or less or a presentation of no more than seven slides. Keep all URLs public and test them in an incognito browser window before submitting.
